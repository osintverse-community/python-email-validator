# python-email-validator (community package)

This repository packages [github.com/JoshData/python-email-validator](https://github.com/JoshData/python-email-validator) for the OTInstaller Registry as `osintverse-community/python-email-validator`. Report problems with the tool upstream, and problems with the packaging here. If you maintain the upstream project and want to publish it yourself, open an issue: the package is transferred to you.
